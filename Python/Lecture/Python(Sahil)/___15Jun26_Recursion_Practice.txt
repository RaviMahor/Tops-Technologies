# Recursion Practice Questions (Medium Level)

Solve the following problems using recursion only. Avoid using loops unless explicitly required.

1. Find the sum of digits of a given positive integer.
   Example: 1234 → 10

2. Find the product of digits of a given positive integer.
   Example: 1234 → 24

3. Count the number of zeros present in a given integer.
   Example: 102030 → 3

4. Reverse a given number using recursion.
   Example: 1234 → 4321

5. Check whether a given string is a palindrome using recursion.
   Example: "madam" → True

6. Find the nth Fibonacci number recursively.
   Example: n = 7 → 13

7. Find the Greatest Common Divisor (GCD) of two numbers using recursion.
   Example: gcd(48, 18) → 6

8. Calculate x raised to the power n using recursion.
   Example: 2^5 → 32

9. Count the occurrences of a specific character in a string using recursion.
   Example: ("programming", "g") → 2

10. Remove all occurrences of a given character from a string recursively.
    Example: ("banana", "a") → "bnn"

11. Find the maximum element in a list using recursion.
    Example: [3, 8, 2, 10, 5] → 10

12. Find the sum of all elements in a list using recursion.
    Example: [1, 2, 3, 4, 5] → 15

13. Generate all binary strings of length n using recursion.
    Example: n = 3 → 000, 001, 010, 011, 100, 101, 110, 111

14. Solve the Tower of Hanoi problem and print all moves.
    Example: n = 3

15. Find all possible subsets (Power Set) of a given list using recursion.
    Example: [1, 2] → [], [1], [2], [1,2]
